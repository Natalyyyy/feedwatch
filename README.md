# feedwatch

Мониторинг чужих публичных Instagram-аккаунтов и Telegram-каналов для
Claude Code: еженедельный отчёт в Telegram (о чём писали, что залетело
по лайкам, комментам и просмотрам) + ежедневный пульс (пост резко
набирает выше медианы своего аккаунта/канала). В каждой строке отчёта —
ссылка на пост.

## Как это работает

- Instagram-данные собираются через **Apify** (любые публичные аккаунты,
  платно) или **Meta Graph API** (бесплатно, только бизнес/креатор-аккаунты)
  — выбор при настройке.
- Telegram-данные собираются через **web** (веб-превью t.me: бесплатно,
  без ключей, посты + просмотры + реакции + подписчики; комментарии
  недоступны) или **TGStat** (нужен платный токен, лимиты по тарифу;
  отдаёт только просмотры) — выбор при настройке.
- Всё хранится локально в SQLite. «Залетело» считается от **медианы**
  лайков/комментов/просмотров конкретного аккаунта или канала за последние
  30 дней — маленькие и большие аккаунты сравниваются честно, в кратных:
  «×2.4 от медианы».
- Отчёты приходят в Telegram через вашего собственного бота.
- Выжимку «о чём писали» пишет Claude (headless). Если вызов не сработал —
  отчёт приходит без неё, только метрики.

## Установка

1. Нужен [Claude Code](https://claude.com/claude-code) и Python 3.9+.
2. Склонируйте репо в папку скиллов:
   `git clone https://github.com/Natalyyyy/feedwatch ~/.claude/skills/feedwatch`
3. Откройте Claude Code и скажите: **«настрой мониторинг соцсетей»** —
   дальше он сам: спросит про платформы и источники, поможет получить ключи,
   создать Telegram-бота, соберёт первые данные и (по желанию) поставит
   расписание.

## Команды после настройки

Говорите Claude: «отчёт по инстаграму», «отчёт по каналам», «проверь
пульс», «добавь @X в мониторинг», «добавь канал @X», «выключи
автоматику», «обнови токен инстаграма».

## Расшифровка рилсов

У рилса подпись — обычно одна строка, а весь смысл в самом видео, поэтому
отчёт по подписям мало что говорит. `reels.py` берёт топ видео недели
(в кратных медианы аккаунта), скачивает файл и снимает речь через Groq
Whisper:

```
python3 reels.py --days 7 --limit 5 --out reels.md
```

С `--frames 6` дополнительно нарежет кадры — это для разбора руками, когда
надо прочитать плашки и субтитры на экране. В автоматике кадры не нужны:
их всё равно никто не открывает.

Нужен `GROQ_API_KEY` в `.env`, плюс установленные `ffmpeg` и `ffprobe`.

Две особенности, о которых стоит знать заранее:

- **Запускать сразу после сбора.** Прямые ссылки на медиа живут на CDN Меты
  считанные часы, поэтому скачать можно только то, что собрано в этом же
  прогоне. Задним числом видео уже не достать.
- **Немой ролик.** Whisper на дорожке без речи не отдаёт пустоту, а выдумывает
  титры вроде «Субтитры сделал…». Такие ответы отбрасываются, в отчёт идёт
  «речь: без слов» — смотреть надо кадры.

Сам файл нигде не оседает: он качается во временную папку и удаляется сразу
после расшифровки. Посмотреть ролик глазами всегда можно по ссылке на пост,
а свежую ссылку на медиа каждый прогон приносит заново. Кадры (если просили
`--frames`) складываются в `FEEDWATCH_DATA_DIR/reels/ГГГГ-ММ-ДД/` и чистятся
ротацией.

## Стоимость

- **Apify**: ~$2.5–3 за 1000 постов. 10 аккаунтов + ежедневный пульс ≈
  $8–10/мес. Бесплатного кредита ($5/мес) хватит попробовать.
- **Groq Whisper** (расшифровка рилсов): доли цента за ролик — минута речи
  стоит примерно $0.002.
- **Meta Graph API**: бесплатно, но настройка сложнее (нужны свой
  IG-бизнес-аккаунт и приложение Facebook) и токен надо обновлять раз в 60 дней.
- **Telegram (web)**: бесплатно, без регистраций.
- **TGStat**: по тарифам tgstat.ru.
- **Claude**: автоматический еженедельный отчёт тратит лимиты вашей подписки.

## Дисклеймер

Скрейпинг Instagram через Apify нарушает условия использования Меты —
используете на свой риск. feedwatch следит только за постами ленты, сторис
он не собирает. Технически Meta Graph API отдаёт по чужим сторис `id`,
`media_type`, `timestamp` и `permalink`, но не `media_url` — то есть их
содержание недоступно, а сама сторис живёт 24 часа. Полезной аналитики из
этого не выходит, поэтому поддержки сторис в инструменте нет. Meta Graph API — легальный путь, но с дополнительными
ограничениями (только бизнес/креатор-аккаунты и не отдаёт просмотры
чужих рилсов — их показывает только Apify).
Веб-превью t.me — публичные данные, которые Telegram отдаёт без
авторизации; TGStat — официальный API по их тарифам. Каналы со скрытым
превью через web-источник недоступны.
Проект не аффилирован с Meta. Meta признана экстремистской организацией
и запрещена на территории РФ.
